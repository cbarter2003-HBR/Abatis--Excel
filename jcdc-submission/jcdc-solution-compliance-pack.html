1Purpose & how to read this pack

4S answered the JCDC Technical Comparison Sheet with Comply against five cyber-security line items (NDR, SIEM, Syslog Server, Endpoint Security & Data Leak) plus four declared Comply-as-Noted deviations. This pack is the engineering evidence behind those answers: what is supplied, how it is configured across the two data centres, how the applications integrate, and how each numbered requirement is met. It consolidates the Architecture Overview v2.1 and the four function papers (DXI/EDR, SIEM-IRIS-Shuffle, XDR, DLP) into one reviewable document — every diagram and matrix row cross-references the specification clause it answers.

One story across documents. The four deviations already declared in TBE-034 are restated verbatim in the matrix below — the comparison sheet, this pack and Implementation Plan V2 must never disagree. Items marked Gap — decide were answered "Comply" on the sheet but still lack a named component: each needs a product addition, a demarcation to another package, or a negotiated deviation before V2 is issued.

3Dual-site high-availability architecture

Both data centres run the full stack as active pairs. Endpoint agents hold an ordered server list (primary site first) and re-home automatically; analysis, casework, playbooks and intelligence replicate continuously across the inter-site link. The design satisfies 272541 §2.3-A (high availability, no permitted downtime), §2.4-I (layered redundancy, no single point of failure) and the data-sovereignty commitments.

Figure 1 — Deployment architecture. Answers 272541 §2.3–2.5 and TBE-034 HA expectations. The indexer quorum arbiter is placed per the V2 partition analysis so the Secondary site remains fully operational during a site partition (Test 3, §7 below).
